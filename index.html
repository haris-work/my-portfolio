C / Algorithms

Huffman Coding Implementation

I built an implementation of the Huffman coding algorithm in C during my early studies. The project focused on constructing Huffman trees, working with frequencies, and implementing the priority queue and tree operations needed for encoding and decoding.

  • Binary trees and node-based data structures
  • Greedy algorithm design
  • Min-heap / priority queue logic
  • Frequency analysis and bit-level encoding
  • Memory handling and pointer-based C implementation
C++ / NLP

Mini Language Model (N-gram Approach)

I built a small statistical language model using N-grams to model word relationships and predict the next token from the previous context. The project focused on frequency counts, probability, token sequences, and basic text-generation behavior without using a neural-network architecture.

  • N-grams and context windows
  • Tokenization and text preprocessing
  • Frequency-based language modeling
  • Conditional probability estimation
  • Text prediction and basic generation
